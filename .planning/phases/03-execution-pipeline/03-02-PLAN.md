  <name>Task 1: Create JobExecutionService with timer, evaluation, concurrency, and crash recovery</name>
  <files>Services/JobExecutionService.cs</files>
  <action>
    Create `Services/JobExecutionService.cs` as a `public sealed class JobExecutionService : IDisposable` in namespace `SSH_Helper.Services`.

    **Constructor dependencies** (manual DI, matching existing service pattern):
    - `JobStorageService jobStorage`
    - `SchedulingService schedulingService`
    - `ConfigurationService configService`

    **Private fields:**
    - `System.Threading.Timer? _timer` -- the 30-second evaluation timer
    - `int _evaluating` -- reentrancy guard (0 = idle, 1 = evaluating), used with `Interlocked.CompareExchange`
    - `SemaphoreSlim _concurrencyGate` -- initialized to `configService.GetCurrent().MaxConcurrentJobs` (or 3 if <= 0)
    - `ConcurrentDictionary<string, RunningJobInfo> _runningJobs` -- tracks active job executions
    - `ConcurrentQueue<QueuedJob> _jobQueue` -- FIFO overflow queue
    - `CancellationTokenSource _disposalCts` -- for clean shutdown
    - `bool _disposed` -- disposal guard
    - `DateTime _lastEvaluationUtc` -- tracks last evaluation time for missed-occurrence window

    **RunningJobInfo** (private nested class, NOT RunningJobState which is the persisted model):
    - `string JobId`
    - `DateTime StartedUtc`
    - `CancellationTokenSource Cts`
    - `bool IsRunNow` (tracks whether this was a manual trigger)

    **Events** (EventHandler<T> pattern matching existing SshExecutionService):
    - `public event EventHandler<JobStateChangedEventArgs>? JobStateChanged`
    - `public event EventHandler<JobRunResult>? JobCompleted`

    Create `JobStateChangedEventArgs` as a nested public class (or place in Models/ if preferred -- use nested for now):
    - `string JobId`, `string JobName`, `JobExecutionState State`, `string? Message`

    **Public methods:**

    1. `public void Initialize()` -- Crash recovery on startup:
       - Iterate `_jobStorage.Jobs.Values.ToList()`
       - For any job where `job.RunningState != null`: log via `System.Diagnostics.Debug.WriteLine($"Orphaned job detected: '{job.Name}' (started {job.RunningState.StartedUtc:u})")`, raise `JobStateChanged` with `JobExecutionState.Failed` and message "Application crashed during execution", clear `RunningState` to null, call `_jobStorage.Save(job)`
       - Must be called BEFORE `Start()`, before timer begins

    2. `public void Start()` -- Start the timer:
       - Guard: if `_disposed` throw `ObjectDisposedException`
       - Create timer: `_timer = new System.Threading.Timer(TimerCallback, null, dueTime: TimeSpan.Zero, period: TimeSpan.FromSeconds(30))`
       - Per locked decision: 30-second evaluation interval, fire immediately for first evaluation

    3. `public void Stop()` -- Pause the timer without disposing:
       - `_timer?.Change(Timeout.Infinite, Timeout.Infinite)`

    4. `public bool IsJobRunning(string jobId)` -- Check if a specific job is currently executing:
       - `return _runningJobs.ContainsKey(jobId)`

    5. `public IReadOnlyList<string> GetRunningJobIds()` -- List currently running job IDs:
       - `return _runningJobs.Keys.ToList()`

    **Private methods:**

    6. `private void TimerCallback(object? state)` -- Timer callback (void, ThreadPool thread):
       - Reentrancy guard: `if (Interlocked.CompareExchange(ref _evaluating, 1, 0) != 0) return;`
       - Fire-and-forget the async evaluation: `_ = EvaluateAndExecuteDueJobsAsync();`
       - Per research: the reentrancy guard release goes in the async method's finally, NOT here

    7. `private async Task EvaluateAndExecuteDueJobsAsync()` -- Core evaluation loop:
       - Wrap entire body in `try { ... } catch (Exception ex) { Debug.WriteLine(...) } finally { Interlocked.Exchange(ref _evaluating, 0); }`
       - `var now = DateTime.UtcNow;`
       - Iterate `_jobStorage.Jobs.Values.ToList()`:
         - Skip if `_disposalCts.IsCancellationRequested`
         - Skip if `!job.IsEnabled`
         - Skip if `job.HasDriftWarning` (per locked decision: drift detection blocks scheduled execution)
         - Skip if `_runningJobs.ContainsKey(job.Id)` (per locked decision: duplicate trigger skipped and logged)
         - For `ScheduleType.Recurring`: call `_schedulingService.GetMissedOccurrences(job.CronExpression, _lastEvaluationUtc)` -- if count == 0, skip; if count > 0, the job is due. Log if skipping due to duplicate.
         - For `ScheduleType.OneTime`: skip if `!job.OneTimeScheduleUtc.HasValue` or if `job.OneTimeScheduleUtc.Value > now`; otherwise it's due
         - For `ScheduleType.None`: skip (manual-only jobs)
         - If job is due: try to acquire semaphore non-blocking via `_concurrencyGate.Wait(0)` (synchronous, zero timeout). If acquired, fire `_ = ExecuteScheduledJobAsync(job)`. If not acquired, enqueue to `_jobQueue` and raise `JobStateChanged(Queued)`.
       - Set `_lastEvaluationUtc = now;`

    8. `private async Task ExecuteScheduledJobAsync(JobDefinition job)` -- Execute with semaphore already acquired:
       - Call `TryStartJob(job.Id)` -- if false, release semaphore and return (duplicate race condition)
       - `try { await ExecuteJobCoreAsync(job, false, _disposalCts.Token); }`
       - `catch (OperationCanceledException) { OnJobStateChanged(job.Id, job.Name, JobExecutionState.Cancelled); }`
       - `catch (Exception ex) { OnJobFailed(job, ex.Message); }`
       - `finally { CompleteJob(job.Id); _concurrencyGate.Release(); DrainQueue(); }`

    9. `private bool TryStartJob(string jobId)` -- Atomic start tracking:
       - Create `CancellationTokenSource cts = new()`
       - Create `RunningJobInfo` with jobId, `DateTime.UtcNow`, cts, `isRunNow: false`
       - `if (!_runningJobs.TryAdd(jobId, info)) { cts.Dispose(); return false; }`
       - Persist RunningState: `var job = _jobStorage.Get(jobId); if (job != null) { job.RunningState = new RunningJobState { StartedUtc = info.StartedUtc }; _jobStorage.Save(job); }`
       - Raise `JobStateChanged(Started)`
       - Return true

    10. `private void CompleteJob(string jobId)` -- Clear tracking:
        - `if (_runningJobs.TryRemove(jobId, out var info)) { info.Cts.Dispose(); }`
        - Clear RunningState: `var job = _jobStorage.Get(jobId); if (job != null) { job.RunningState = null; _jobStorage.Save(job); }`

    11. `private void DrainQueue()` -- Dequeue waiting jobs when slots free:
        - `while (_jobQueue.TryPeek(out var queued) && _concurrencyGate.Wait(0))`
          - `if (_jobQueue.TryDequeue(out queued))`
            - `var job = _jobStorage.Get(queued.JobId);`
            - `if (job != null && job.IsEnabled && !_runningJobs.ContainsKey(job.Id))`
              - `_ = ExecuteScheduledJobAsync(job);`
            - `else _concurrencyGate.Release();` -- slot not used, release it back
          - `else _concurrencyGate.Release();` -- peek succeeded but dequeue failed (race), release

    12. `private async Task ExecuteJobCoreAsync(JobDefinition job, bool isRunNow, CancellationToken ct)` -- PLACEHOLDER for Plan 03:
        - For now: `await Task.Delay(100, ct);` -- stub that does nothing
        - Raise `JobCompleted` event with a minimal `JobRunResult` (Success=true, 0 hosts)
        - Raise `JobStateChanged(Completed)`
        - Plan 03 replaces this with real SSH execution logic
        - **Add a comment:** `// TODO: Plan 03-03 replaces this stub with real SSH execution`

    13. Helper methods:
        - `private void OnJobStateChanged(string jobId, string jobName, JobExecutionState state, string? message = null)` -- raises `JobStateChanged` event
        - `private void OnJobFailed(JobDefinition job, string errorMessage)` -- raises both `JobStateChanged(Failed)` and `JobCompleted` with failure result

    **Dispose pattern:**
    - `_disposalCts.Cancel()` first
    - `_timer?.Dispose()`
    - Cancel all running jobs: `foreach (var info in _runningJobs.Values) info.Cts.Cancel();`
    - `_concurrencyGate.Dispose()`
    - `_disposalCts.Dispose()`
    - Set `_disposed = true`

    **CRITICAL anti-patterns to avoid** (from research):
    - Do NOT use `async void` for the timer callback -- use `void` callback that fire-and-forgets an `async Task`
    - Do NOT put the reentrancy guard release in the timer callback -- put it in the async method's `finally`
    - Do NOT access any WinForms controls -- this runs on ThreadPool threads
    - Do NOT share the UI's SshExecutionService instance -- Plan 03 creates per-job instances
    - Always `try/finally` around semaphore acquire/release to prevent leaks
