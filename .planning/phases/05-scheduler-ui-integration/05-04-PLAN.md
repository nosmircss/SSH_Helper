    Layout:
    - ToolStrip at top with buttons: New, Edit, Run Now, Enable/Disable, Delete, Duplicate, separator, Export File, Export Clipboard, Import File, Import Clipboard
    - SplitContainer _mainSplit (Dock.Fill, Orientation.Horizontal, SplitterDistance ~60%):
      - Panel1: DataGridView _gridJobs (job list)
      - Panel2: Panel containing:
        - Label "Run History" (Dock.Top, bold)
        - DataGridView _gridHistory (Dock.Fill)
        - FlowLayoutPanel at bottom with: "View Output" button, "Clear History" button
    - ContextMenuStrip on _gridJobs with same actions as toolbar

    Job grid columns (as specified in CONTEXT.md):
    - Name (TextBox, FillWeight 25)
    - Enabled (CheckBox, FillWeight 5, header "On")
    - Schedule (TextBox, FillWeight 20) - human-readable cron or one-time date
    - NextRun (TextBox, FillWeight 15)
    - LastResult (TextBox, FillWeight 20)
    - Target (TextBox, FillWeight 15)
    - ReadOnly, FullRowSelect, MultiSelect true, no user add/delete
    - Style via DialogTheme.StyleDataGridView

    History grid columns:
    - Started (TextBox, FillWeight 20) - CompletedUtc.ToLocalTime().ToString("g")
    - Duration (TextBox, FillWeight 10) - (CompletedUtc - StartedUtc) formatted as "mm:ss" or "HH:mm:ss"
    - Result (TextBox, FillWeight 15) - "OK (X/Y)" or "FAIL (X/Y)" with host counts
    - Error (TextBox, FillWeight 30) - ErrorMessage or empty
    - ReadOnly, FullRowSelect, SingleSelect

    RefreshJobList method (same pattern as RESEARCH.md code example):
    - Iterate _jobStorage.Jobs.Values.OrderBy(j => j.Name)
    - For each job: compute schedule description, next run, last run result from services
    - Store job.Id in row.Tag for retrieval
    - Running jobs: set Name cell ForeColor to green/lime (discretion: visual running indicator)
    - Drift warning jobs: set Name cell ForeColor to orange, append " [DRIFT]" to name display

    RefreshHistory method:
    - When job selected in _gridJobs, load history via _historyService.GetRunsForJob(jobId)
    - Store RunFileName in history row.Tag for output loading
    - Clear history grid when no job selected

    Timer refresh:
    - System.Windows.Forms.Timer _refreshTimer (Interval = 5000ms)
    - On tick: call RefreshJobList() (preserves selection by saving/restoring selected job ID)
    - Start timer on form load, stop on FormClosing

    Event subscriptions:
    - _jobStorage.JobsChanged += handler (triggers RefreshJobList on UI thread via BeginInvoke)
    - _executionService.JobStateChanged += handler (triggers RefreshJobList on UI thread via BeginInvoke)
    - _executionService.JobCompleted += handler (triggers RefreshJobList on UI thread via BeginInvoke)
    - Unsubscribe all events in OnFormClosing

    Dialog chrome:
    - Title: "Scheduled Jobs"
    - Size: 1000x700, MinimumSize 800x500, StartPosition CenterParent
    - Apply DialogTheme.ApplyTo + SetDarkTitleBar + SetDialogFont

<task type="auto">
  <name>Task 2: Wire toolbar actions, export/import, and editor integration</name>
  <files>JobListDialog.cs</files>
  <action>
    Add action handlers to the existing JobListDialog:

    **New button:**
    - Open JobEditorDialog with existingJob=null
    - On DialogResult.OK: call _jobStorage.Save(editor.Result), RefreshJobList()

    **Edit button (also double-click on grid row):**
    - Get selected job from _gridJobs row.Tag
    - Open JobEditorDialog with the job
    - On DialogResult.OK: call _jobStorage.Save(editor.Result), RefreshJobList()

    **Run Now button:**
    - Get selected job from _gridJobs
    - Call `await _executionService.RunNowAsync(jobId)` (fire-and-forget from UI)
    - If returns false, show DialogTheme.Show("Cannot run job: ...")

    **Enable/Disable button:**
    - Get selected job, toggle IsEnabled, call _jobStorage.Save(job), RefreshJobList()

    **Delete button:**
    - Confirm via DialogTheme.Confirm("Delete job '{name}'?", "Delete Job")
    - If confirmed: _jobStorage.Delete(jobId), _historyService.DeleteAllHistory(jobId), RefreshJobList()

    **Duplicate button:**
    - Get selected job, deep clone via JsonConvert
    - Set new GUID, append " (copy)" to name, set ModifiedUtc = UtcNow
    - Save via _jobStorage.Save(clone), RefreshJobList()

    **Export File button:**
    - Get selected job(s) from _gridJobs (multi-select)
    - SaveFileDialog with filter ".sshjobs files (*.sshjobs)|*.sshjobs"
    - Call _exportService.ExportToFile(selectedJobs, filePath)
    - Show confirmation: "Exported N job(s) to {filename}"

    **Export Clipboard button:**
    - Get selected job(s) from _gridJobs
    - Call _exportService.ExportToString(selectedJobs)
    - Clipboard.SetText(result)
    - Show confirmation: "Copied N job(s) to clipboard"

    **Import File button:**
    - OpenFileDialog with filter ".sshjobs files (*.sshjobs)|*.sshjobs"
    - Call _exportService.ImportFromFile(filePath)
    - If empty: show error "Could not read job file"
    - Call _exportService.PrepareImport(jobs, existingNames)
    - Set MissingTarget flag by checking _presetManager.Presets/Folders
    - Show ImportPreviewDialog
    - On OK: foreach accepted entry: _jobStorage.Save(entry.Job with ResolvedName), RefreshJobList()

    **Import Clipboard button:**
    - Get text from Clipboard.GetText()
    - Call _exportService.ImportFromString(text)
    - Same flow as Import File after parsing

    **View Output button (history panel):**
    - Get selected history row from _gridHistory
    - Load payload: _historyService.LoadRunPayload(jobId, runFileName)
    - If null: show error "Could not load run output"
    - Show RunOutputViewerDialog(payload, _darkMode)

    **Clear History button (history panel):**
    - Get selected job from _gridJobs
    - Confirm: "Clear all history for '{jobName}'?"
    - Call _historyService.DeleteAllHistory(jobId), RefreshHistory()

    **Selection change on _gridJobs:**
    - Call RefreshHistory() for the newly selected job

    **Keyboard shortcuts:**
    - Delete key on _gridJobs: trigger Delete action
    - Enter/F2 on _gridJobs: trigger Edit action
    - F5: trigger RefreshJobList()
