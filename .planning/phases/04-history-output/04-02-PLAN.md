  <action>
Create `Services/JobHistoryService.cs` as a `public sealed class JobHistoryService`.

**Constructor:**
- Accept optional `string? basePath = null`
- Default to `Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "SSH_Helper", "job-history")`
- Store as `_baseDirectory`

**Event subscription:**
- `public void SubscribeTo(JobExecutionService executionService)` -- subscribes `OnJobCompleted` to `executionService.JobCompleted`
- `private void OnJobCompleted(object? sender, JobRunResult result)` -- calls `SaveRun(result, maxRuns, retentionDays, maxOutputChars)` with default values. Note: the caller (Form1) will need to set up defaults; for now use constants: `DefaultMaxRuns = 50`, `DefaultRetentionDays = 30`, `DefaultMaxOutputChars = 1_048_576`

**SaveRun method:**
- `public void SaveRun(JobRunResult result, int maxRuns = 50, int retentionDays = 30, int maxOutputChars = 1_048_576)`
- Generate run ID via `HistoryIdGenerator.NewId()`
- Build `JobRunPayload` from result, truncating each host's output via `TruncateOutput(output, maxOutputChars)`
- Build `JobRunRecord` (lightweight index entry) with `RunFileName = $"{runId}.json"`
- Ensure job subdirectory exists: `Directory.CreateDirectory(GetJobDirectory(result.JobId))`
- Write payload file atomically: `JsonFileWriter.WriteJsonAtomic(payloadPath, serializedPayload, createBackup: false)`
- Load existing index, prepend new record (newest first), save index atomically: `JsonFileWriter.WriteJsonAtomic(indexPath, serializedIndex, createBackup: true)`
- Call `EnforceRetention(result.JobId, maxRuns, retentionDays)`

**TruncateOutput (private static):**
- If `output.Length <= maxChars`, return as-is
- Build truncation marker: `$"\n[... output truncated: {output.Length - maxChars:N0} characters removed ...]\n"`
- Keep first `maxChars - marker.Length` characters + marker
- Handle edge case where `keepChars <= 0` (just return marker)

**LoadJobIndex (private):**
- Read `{jobDir}/index.json`, deserialize to `JobRunIndexDocument`
- If file doesn't exist, return new empty document
- If deserialization fails, call `TryBackupCorruptFile(indexPath)` and return empty document
- Mirror the corrupt recovery pattern from HistoryStorageService

**TryBackupCorruptFile (private):**
- Rename corrupt file with timestamp suffix: `$"{path}.corrupt_{DateTime.UtcNow:yyyyMMddHHmmss}"`
- Swallow exceptions (best-effort)

**EnforceRetention (private):**
- Load index for the job
- Phase 1 -- age-based: remove entries where `CompletedUtc < DateTime.UtcNow.AddDays(-retentionDays)`. Delete each removed entry's payload file
- Phase 2 -- count-based: while `Entries.Count > maxRuns`, remove the last entry (oldest, since newest-first). Delete each removed entry's payload file
- If any entries were removed, save the updated index atomically

**Helper methods:**
- `private string GetJobDirectory(string jobId)` => `Path.Combine(_baseDirectory, jobId)`
- `private string GetIndexPath(string jobId)` => `Path.Combine(GetJobDirectory(jobId), "index.json")`
- `private string GetRunFilePath(string jobId, string runFileName)` => `Path.Combine(GetJobDirectory(jobId), runFileName)`
- `private static string Serialize(object obj)` => `JsonConvert.SerializeObject(obj, Formatting.Indented)`

**Serialization:** Use `Newtonsoft.Json` (`JsonConvert.SerializeObject` / `DeserializeObject`) matching project convention.

<task type="auto">
  <name>Task 2: Add query API, search, and deletion to JobHistoryService</name>
  <files>Services/JobHistoryService.cs</files>
  <action>
Add the remaining public methods to `JobHistoryService`:

**GetRunsForJob (query API -- HIST-04):**
- `public IReadOnlyList<JobRunRecord> GetRunsForJob(string jobId, JobRunFilter? filter = null)`
- Load index for jobId
- Apply filters in this order:
  1. `filter.Success.HasValue` => filter by `r.Success == filter.Success.Value`
  2. `filter.FromUtc.HasValue` => filter by `r.CompletedUtc >= filter.FromUtc.Value`
  3. `filter.ToUtc.HasValue` => filter by `r.CompletedUtc <= filter.ToUtc.Value`
- Take `filter?.MaxResults ?? 50` entries
- Return as `IReadOnlyList<JobRunRecord>`
- Entries are already newest-first from SaveRun insertion order

**LoadRunPayload (load full run on demand -- HIST-02):**
- `public JobRunPayload? LoadRunPayload(string jobId, string runFileName)`
- Read the payload JSON file from `GetRunFilePath(jobId, runFileName)`
- If file doesn't exist, return null
- Deserialize to `JobRunPayload`, return null on failure (corrupt file -- log or ignore)

**SearchRunOutput (search within single run -- HIST-04):**
- `public IReadOnlyList<JobHostOutput> SearchRunOutput(string jobId, string runFileName, string searchText)`
- Load the full run payload via `LoadRunPayload`
- If payload is null, return empty list
- Filter `HostOutputs` where `output.Output.Contains(searchText, StringComparison.OrdinalIgnoreCase)` OR `output.HostAddress.Contains(searchText, StringComparison.OrdinalIgnoreCase)`
- Return matching `JobHostOutput` entries

**DeleteAllHistory (cleanup for job deletion -- per CONTEXT.md):**
- `public void DeleteAllHistory(string jobId)`
- Get job directory path
- If directory exists, `Directory.Delete(jobDir, recursive: true)`
- Swallow exceptions (best-effort cleanup)

**DeleteRun (single run deletion):**
- `public void DeleteRun(string jobId, string runId)`
- Load index, find entry with matching Id, remove it
- Delete the payload file
- Save updated index

**GetJobIds (list all jobs with history):**
- `public IReadOnlyList<string> GetJobIds()`
- Enumerate subdirectories of `_baseDirectory`
- Return directory names (which are job IDs)
- Return empty list if base directory doesn't exist

**ClearHistory (per-job manual clear for Phase 5 button):**
- `public void ClearHistory(string jobId)`
- Delete all files in the job's subdirectory except recreate an empty index
- Or equivalently: `DeleteAllHistory(jobId)` then let next SaveRun recreate the directory
- Simpler: just delete the directory. Same as `DeleteAllHistory`.
- Alias: `public void ClearHistory(string jobId) => DeleteAllHistory(jobId);`
