    - DetectMissedRuns skips disabled jobs
    - DetectMissedRuns skips jobs with ScheduleType != Recurring
    - DetectMissedRuns skips jobs with null/empty CronExpression
    - MarkOneTimeCompleted sets IsEnabled=false, DisabledReason="One-time schedule completed", preserves OneTimeScheduleUtc
  </behavior>
  <action>
    1. Write tests FIRST in SSH_Helper.Tests/Services/SchedulingServiceTests.cs covering all behavior cases above.

    2. Create Services/SchedulingService.cs as a sealed class with these methods:
       - `string? ValidateCronExpression(string expression)` -- delegates to Cronos TryParse, 5-field only (do NOT pass CronFormat.IncludeSeconds). Returns null if valid, error message if invalid.
       - `string? GetDescription(string expression)` -- validates first with TryParse, then calls ExpressionDescriptor.GetDescription with Use24HourTimeFormat=false and ThrowExceptionOnParseError=false. Returns null on invalid input.
       - `DateTime? GetNextRunLocal(string cronExpression)` -- uses GetNextOccurrence(DateTimeOffset.UtcNow, TimeZoneInfo.Local), returns nullable LocalDateTime.
       - `DateTime? GetNextRunUtc(string cronExpression)` -- uses GetNextOccurrence(DateTime.UtcNow), returns nullable UTC DateTime.
       - `IReadOnlyList<DateTime> GetMissedOccurrences(string cronExpression, DateTime lastCheckedUtc)` -- uses GetOccurrences(lastCheckedUtc, DateTime.UtcNow, fromInclusive: false, toInclusive: false).
       - `IReadOnlyList<SkippedRunEntry> DetectMissedRuns(IReadOnlyDictionary<string, JobDefinition> jobs, DateTime lastAppShutdownUtc)` -- iterates enabled recurring jobs, calls GetMissedOccurrences for each, returns SkippedRunEntry list.
       - `void MarkOneTimeCompleted(JobDefinition job)` -- sets job.IsEnabled=false, job.DisabledReason="One-time schedule completed". Does NOT clear OneTimeScheduleUtc (per user decision: keep visible as record).

    3. All DateTime calculations MUST use UTC internally. Only GetNextRunLocal converts to local for display.
