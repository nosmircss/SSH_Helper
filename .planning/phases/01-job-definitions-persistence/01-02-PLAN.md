  <action>
Create `Services/JobStorageService.cs` as a `public sealed class` in `SSH_Helper.Services` namespace.

**Constructor:** Accept `ICredentialProvider credentialProvider` (required, guard with ArgumentNullException) and `string? jobsFilePath = null` (optional for test isolation). If no path provided, use `%LocalAppData%\SSH_Helper\jobs.json` (mirror ConfigurationService constructor exactly). Store both as readonly fields.

**Internal state:**
- `private readonly Dictionary<string, JobDefinition> _jobs = new();`
- `private bool _loaded;`
- `public string? LoadError { get; private set; }` (like ConfigurationService.ConfigLoadError)

**Public API:**
- `public IReadOnlyDictionary<string, JobDefinition> Jobs => _jobs;`
- `public string JobsFilePath => _jobsFilePath;`
- `public event EventHandler? JobsChanged;`

**Load():** Read jobs.json, deserialize a wrapper `{ "Version": 1, "Jobs": [...] }`. Populate `_jobs` keyed by `job.Id`. On JsonException/corrupt: copy file to `.corrupt`, set `LoadError`, start with empty dictionary. On file not found: empty dictionary, no error. Set `_loaded = true`.

**Save(JobDefinition job):** Validate: not null, Name not empty, Name trimmed, Name max 100 chars. Enforce unique name (case-insensitive) EXCLUDING the job being saved (so rename of same job is allowed). If new job (Id not in _jobs), use Id and CreatedUtc as-is. Always set `ModifiedUtc = DateTime.UtcNow`. Upsert into `_jobs`. Call `PersistToDisk()`. Raise `JobsChanged`.

**Delete(string jobId, bool cleanupCredentials = true):** Remove from `_jobs`. If job had `CredentialMode.Stored` and `cleanupCredentials`, call `_credentialProvider.DeletePassword(CredentialTargets.JobPasswordTarget(jobId))`. Call `PersistToDisk()`. Raise `JobsChanged`. Return true/false.

**Get(string jobId):** Simple dictionary lookup, return null if not found.

**GetJobsReferencingPreset(string presetName):** Filter `_jobs.Values` where `TargetType == Preset` and `TargetName` matches case-insensitively. Return `IReadOnlyList<JobDefinition>`.

**GetJobsReferencingFolder(string folderPath):** Same pattern for `TargetType == Folder`.

**Reload():** Clear `_jobs`, reset `_loaded`, call `Load()`.

**PersistToDisk() (private):** Mirror ConfigurationService.Save() pattern -- backup current file to `.bak` (best-effort), serialize wrapper object with `JsonConvert.SerializeObject(wrapper, Formatting.Indented)`, `File.WriteAllText`.

**JobsFileWrapper (private nested class):** `public int Version { get; set; } = 1;` and `public List<JobDefinition> Jobs { get; set; } = new();`

Use `Newtonsoft.Json` for serialization (project standard). Follow the `sealed` class convention. Use guard clauses.

Write tests FIRST. Use temp directory for file isolation (same pattern as ConfigurationService tests). Mock `ICredentialProvider` using Moq for Delete credential cleanup tests.
