send — Execute SSH Commands

Executes a command on the SSH session. Use the map form when you need options.

# FortiGate health check across the fleet
- send:
    command: get system performance status
    capture: perf_out
    expect: '/# $/'
    timeout: 30
    retry: 3
OptionTypeDescription
capturestringVariable name to store command output
expectstringRegex to wait for; completes on match
retryintegerRetries on failure (default: 0)
