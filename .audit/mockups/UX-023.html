One contract, all prompts Yes → "true", continue No → "false", continue Cancel → step fails → on_error / on_cancel 
- confirm:
    prompt: "Reboot core switch {{Host_IP}}?"
    into: reboot_ok
    allow_cancel: true      # new — distinct from No
  on_cancel: exit          # same contract for input / choose / multiselect / readfile / writefile
