# Flow Canvas state & layout (React) — subsystem map

Scope: `FlowCanvas/src/stores/` (slices, selectors, reflow, bridges), `FlowCanvas/src/utils/` (layout engine, exportGraph, childMembership, displayNodes, connectionRules, blockSummary, nodeStyle, clipboard, tokens, theme, nodeSize, branchBands, layoutAutosave, runOutputClassify), `MessageBus.ts`, `communication-message-types.ts`, `panelMode.ts`. All paths relative to `FlowCanvas/src/`. Line refs verified 2026-06-10.

The store is a single flat Zustand store composed of 11 slices (`stores/useFlowStore.ts:26-38`): Graph, Execution, Debug, Variable, Undo, Timeline, UI, Comment, Host, Settings, Iteration. There is **no persistence middleware** — all persistence flows through explicit WebView2 messages to the C# host (`layout-save`, `layout-autosave`, `pref-save`), restored via `layout-restore` / `pref-restore` / `load-graph`.

## Feature inventory

### 1. Graph state & mutation pipeline (`stores/slices/graphSlice.ts`, 640 LOC)
Holds `nodes`, `edges`, `selectedNodeIds`/`selectedEdgeIds` (Sets), `isDirty` (graphSlice.ts:194-223). Every structural mutation clears `exportStatus`/`diagnostics` via `clearedExportStatusState()` (graphSlice.ts:23-32) so stale apply-errors never block a re-run.

- **`onNodesChange`** (graphSlice.ts:243-326): filters out removal of the synthetic `__start__` node (graphSlice.ts:244-246, `START_NODE_ID` at :12); cascades removal to comments attached to deleted blocks (graphSlice.ts:267-283); **drag-follow** moves anchored comments by the same delta as their host block (graphSlice.ts:288-308); renumbers `_stepPath` after removals (graphSlice.ts:314, see invariant §6); reflows only when a **space-reserving** comment leaves (graphSlice.ts:252-264, 325 — gate is `anchorReservesLayoutSpace`, deliberately narrower than "any attached comment").
- **`onEdgesChange`** (graphSlice.ts:328-344): deleting a wire that conferred membership reverts the target to an orphan via `clearConnectAuthoredMembership` + renumber (graphSlice.ts:332-336).
- **`onConnect`** (graphSlice.ts:346-420): runs the connection guard first (`isConnectionAllowed`, rejects with a toast via `showConnectionNotice` :350-354), pushes an undo snapshot (:356), infers default branch metadata for container sources (`inferDefaultBranchMetadata`, graphSlice.ts:70-136 — if→then/elif-N/else, foreach/while→do, try→try/catch/finally (4th branch falls back to `catch` :113), switch→`cases/N/do` with `case_N+1` value, parallel→`parallel/N`), styles the edge (`getBranchVisual` :138-192, colors via `branchColorVar`; continuation edges get accent `next` label :397-402), and **confers band membership** on freshly-wired blocks via `deriveChildMembership`/`applyChildMembership` (:377-395), including the orphan **re-home** path (`targetIsOrphaned` seam :383-388) with renumber of the vacated branch.
- **`addNode`/`removeNodes`/`removeEdges`** (graphSlice.ts:422-476): all push undo snapshots; `removeNodes` resolves the full cascade set (attached comments incl. inline) up-front and reflows only for reserving comments (:436-457).
- **`updateNodeProp`** (graphSlice.ts:510-562): writes one prop and walks the `_isChildOf` ancestor chain setting `_forceGraphExport: true` on every container ancestor (graphSlice.ts:516-534, 546-548) — the contract that makes export regenerate edited containers from the graph instead of replaying their stale YAML snippet.
- **`updateEdgeBranchMetadata`** (graphSlice.ts:564-597): edits branchPath/condition/caseValue on an edge and re-derives the visual; the only route to author a switch `default` branch (inference never produces it).
- **`translateNodesBy`** (graphSlice.ts:606-614): batched delta move used by band-label dragging (`BranchBandsLayer.tsx:28` pushes the `Move band` snapshot).
- Selection API: `selectNode`/`toggleNodeSelection`/`selectNodes`/`selectEdge`/`clearSelection` (graphSlice.ts:478-483, 616-635).

### 2. Connection rules (`utils/connectionRules.ts`)
`isConnectionAllowed` (connectionRules.ts:9-55) rejects: incomplete, self-loop, edge into Start, exact-duplicate edge, **fan-in** (target already has any incoming edge :25-26), per-handle uniqueness (containers may emit multiple empty-bottom-handle branch edges, non-containers exactly one successor; named handles `continue`/`false` one each :30-47), and cycles via DFS reachability (:49-53, 57-75). Reasons are user-facing strings surfaced as the connection notice (uiSlice `connectionNotice`, nonce-keyed for retrigger, uiSlice.ts:66, 364-366).

### 3. Child membership & `_stepPath` invariants (`utils/childMembership.ts`, 325 LOC)
The import-vs-canvas seam: container membership is decided by **node metadata** (`_isChildOf` + index-precise `_stepPath`), not edges (header comment childMembership.ts:1-12).
- **`deriveChildMembership`** (childMembership.ts:61-124): three gestures confer membership — container `continue` handle → next sibling after the container; leaf bottom handle → next sibling after the leaf; container branch handle → first child of that branch. Returns null for top-level/canvas-authored sources (no `_stepPath` :85) or still-anchored targets (don't-clobber guard :75); an orphaned member (entry edge deleted) is re-homed (`rehome` :78-81). Copies cosmetic keys `_branchLabel`/`_branchColor`/`_depth` from the sibling (:38-39, 120-122). Marks wire-authored membership with `_membershipFromConnect` (:41).
- **`applyChildMembership`** (childMembership.ts:147-211): writes the target's metadata, bumps later siblings (+ whole subtrees) +1 (`bumpStepPath` :129-140), flags the ancestor chain (and on re-home the vacated parent's chain) `_forceGraphExport` (:154-163), and rewrites a re-homed container's **descendant** paths from the old prefix to the new in the same pass (:165-176, 199-203).
- **`renumberStepPaths`** (childMembership.ts:229-296): re-derives contiguous indices per branch scope, recursively, sorted by old trailing index; leaves canvas-authored nodes (no `_stepPath`) and dangling/malformed metadata untouched (:267-270). Wired into **every** removal path (removeNodes graphSlice.ts:451, onNodesChange :314, onEdgesChange :336, removeEdges :467) and into re-home (:394). **Invariant:** the executor assigns sequential paths to exported YAML; any gap silently kills step-update/step-output correlation from the gap onward (doc comment :217-227).
- **`clearConnectAuthoredMembership`** (childMembership.ts:304-325): deleting the conferring wire strips `_isChildOf`/`_stepPath`/marker/cosmetics — imported membership (no marker) is never touched.

### 4. Hierarchical layout engine (`utils/layout/`)
- **`treeBuilder.ts`** (`buildLayoutTree` :32-166): builds spine + per-container branches. Dual origin: `buildBranchesMeta` groups children by `_isChildOf` + branch scope from `_stepPath` (:72-92); `buildBranchesEdges` is the canvas-built fallback following non-`continue` edges (:97-124). Spine walk starts from `__start__`'s first edge; `keepOrphans=true` (automatic reflows) leaves disconnected nodes out of the tree so they keep position; `false` (Auto-Layout button, import) appends them to the spine (:159-163).
- **`branchScope.ts`**: scope extraction (`branchScopeFromStepPath` :6-16) and left-to-right ordering (`branchSortRank` :32-38; then<elif<else, try<catch<finally, cases in order).
- **`hierarchicalLayout.ts`**: `LAYOUT` constants (hierarchicalLayout.ts:7-29; `BRANCH_CHILD_OFFSET` 220 with the documented gutter invariant `offset > blockWidth/2 + BAND_PAD`, `MAX_NESTING_DEPTH` 5, `MAX_SPREAD_WIDTH` 1400). `resolveSizing` (:38-50) maps user Display Settings (blockWidth/density/textScale/compactComments) onto geometry — `branchOffset = blockWidth/2 + BAND_PAD + 37` keeps the spine gutter at every width. **`sizing` param is required by design** (:301-307) after the "silent default reverted wide graphs to 330/1/1" bug. `measureSteps` (:108-145) reserves columns + rows + nested `indent` (each arm's full slot incl. lane padding) so sibling lanes never overlap; `placeMultiBranch` (:179-204) clamps column width to `MAX_SPREAD_WIDTH`. Anchored-comment space is **reserved inside the layout** (`commentReserveByTarget` :74-77, consumed at :164, 217), with `estimateCommentStep` (:63-72) sizing pill vs card. `placeComments` (:233-279) stacks leading/header pills above the block, branch pills above the band header, and parks free comments in a right gutter; falls back to a kept-orphan's current position (:237-238, 262). `anchorReservesLayoutSpace` (:288-294) is the **single source of truth** for both the reserve rule and every reflow trigger. `placeNewBlocksNearNeighbors` (:342-377) is the Manual-mode placement for blocks added in the text editor: drop below predecessor, nudge off occupied points, tag `data._justPlaced` (cleared by `BaseBlock.tsx:131-137` after the entrance pulse).
- **`placeAnchoredComments.ts`** (:13-49): Manual-mode/keep-path comment re-anchoring (blocks frozen, comments stacked above their block/band).

### 5. Auto-flow vs Manual layout mode
- State: `layoutMode` (active preset) + `defaultLayoutMode` (global default for new presets) in uiSlice (uiSlice.ts:35-36, 125-126).
- **`reflowLayout`** (`stores/reflow.ts:17-29`) is the single gate every automatic reflow goes through: `auto` → `computeHierarchicalLayout(..., {keepOrphans: true})`; `manual` → `placeAnchoredComments` only (blocks frozen). Callers: comment add/remove (commentSlice.ts:41, 82), expand/collapse (debugSlice.ts:89, 103), display-settings changes (settingsSlice.ts:58-62), compact-comments toggle/restore (uiSlice.ts:189, 196), graphSlice comment-removal paths (graphSlice.ts:325, 457).
- **`setLayoutMode`** (uiSlice.ts:199-210): echoes `set-layout-mode` to the host; switching to `auto` reflows immediately; switching to `manual` **freezes** current positions via `flushLayoutAutosave()`. `restoreLayoutMode` (:211) is the no-echo host-driven path used by `load-graph`.
- **`load-graph` mode-aware load** (messageBridge.ts:144-160): host sends `layoutMode` + `layoutAction` (`reflow` runs full layout; `keep` preserves host-merged positions and near-neighbor-places only `newNodeIds`) — documented in communication-message-types.ts:1-8. Host-side prefix-safe tuple merge (`stepPath:blockType`) lives in C# (`TryMergeLayoutByTuple`).
- Explicit **Auto-Layout button** (`hooks/useAutoLayout.ts:12-19`): undo snapshot + full layout with `keepOrphans` default false (organizes orphans), threading live sizing.

### 6. Layout autosave (`utils/layoutAutosave.ts`)
`sendLayoutAutosave` debounced 300ms (:14-17), `flushLayoutAutosave` immediate (:20-23). Payload (:25-69): per-node positions **with `stepPath` + `blockType`** (the tuple the host's Manual-mode merge keys on), full comment data, `disabledBlocks`, `expandedNodes`. Triggered by: drag stop (App.tsx:176-179), comment add/update/remove, expand toggles, disable toggle, display-settings commit, Manual-mode freeze.

### 7. Display settings (`stores/slices/settingsSlice.ts` + `canvasSizing.ts`)
`blockWidth` slider 300–2000 (default 330), `textScale` 0.9–2.5, `density` Tight/Normal/Roomy (0.85/1/1.2), `defaultBlockExpanded` (settingsSlice.ts:11-27). Setters reflow + persist via `layout-save` + autosave positions (`reflowAndPersist` :58-62); `opts.persist=false` is the slider live-drag path (reflow-only preview, commit on release :67-75). `setDefaultBlockExpanded` applies to the open graph immediately via `setAllExpanded` (:78-85); `resetCanvasSettings` mirrors the collapse (:86-94). `restoreCanvasSettings` (:97-107) handles the fresh-open ordering where `layout-restore` arrives **after** `load-graph` (re-applies expansion / reflows at restored sizing). `selectCanvasSizing` lives in the runtime-leaf `canvasSizing.ts:11-18` specifically to break a graphSlice→reflow→settingsSlice→layoutAutosave→useFlowStore init cycle (doc comment canvasSizing.ts:4-10).

### 8. UI slice (`stores/slices/uiSlice.ts`, 373 LOC)
- Persisted-via-host toggles (each `toggleX` echoes `layout-save`/`pref-save`, each `restoreX` is no-echo): reducedMotion (pref-save; also OS-seeded pre-`ready` at messageBridge.ts:505-506), heatmap, branch bands (default ON), compact comments (reflows on toggle AND restore — uiSlice.ts:184-197), snap-to-grid (gridSize fixed 20, uiSlice.ts:38/128), layout modes (§5), run-output prefs (color/wrap/follow).
- Search (uiSlice.ts:226-273): substring match over label, blockType, def label, and `JSON.stringify(props)`; results/index/visibility with wraparound next/prev. Ctrl+F toggle.
- Context menus (node + edge), panel visibility map (variables/debug/output/timeline/problems), panel sizes (right panel 600 / output 200 defaults, persisted on resize uiSlice.ts:289-296).
- Run Output console state: `outputTab` block/run, unread dot, popped-out flag; `openRunOutputWindow`/`closeRunOutputWindow` message the host and flip dock state (uiSlice.ts:335-345).
- `exportStatus` + per-node `diagnostics` (set from `apply-result`), `connectionNotice`, and `uiZoomScale` — inverse-zoom chrome scale, quantized to 0.05, capped at 2.25 (uiSlice.ts:25-27, 368-372; fed from RF `onMove` App.tsx:377).

### 9. Execution state (`stores/slices/executionSlice.ts`)
Transient per-run Maps (never on node.data except the mirrored `execState` visual via `updateNodeData`, executionSlice.ts:76): `blockStates`, `blockOutputs` (append-only list per node with stepType), `blockTimings`, `loopIterations`, `branchTaken`, `dataBlockTestResults`. `pathVisible` is the only gate the "Clear Path" control flips (`clearPath` also resets iteration selections :114-117). `runOutput` is the live mirror of the main form's output, capped at 5000 lines (:4, 119-127). `clearExecution` resets all maps and stamps every node `execState:'idle'` (:131-149).

### 10. Debug state (`stores/slices/debugSlice.ts`)
`breakpoints`, `disabledBlocks`, `expandedNodes` Sets + `paused`/`pausedAtNodeId`/`callStack`. `toggleBreakpoint`/`toggleDisabled` update node visuals and message the host (`breakpoint-toggle`, `disable-block`; disable also autosaves layout, debugSlice.ts:41-76). `toggleExpanded`/`setAllExpanded` write the `expanded` carrier flag on node.data (NOT props — never leaks into YAML, :87), reflow, autosave; `setAllExpanded(opts.autosave=false)` is the host-restore path that must not rewrite a preset's saved layout (:25-27, 104). `debugAction` validates against the `continue|step|stop` enum and optimistically un-pauses on stop/continue (:119-132).

### 11. Iteration replay (`stores/slices/iterationSlice.ts` + `stores/selectors/iterationScope.ts`)
Post-run per-loop iteration stepper. `recordIterationEvent` (iterationSlice.ts:103-166) writes every `iterationStack`-tagged event to **all frames** of the stack (ancestors aggregate; error sticky :148), keying records by monotonic `seq` (not `i`, not array position — doc :50-53), starting fresh records when iteration index or parent seq changes (:121-127), evicting beyond `iterationHistoryCap` (default 500, host-persisted :8, 222-231) with documented dangling-parent tolerance (:140-143). Variable snapshots are sanitized: heavy keys `_outputwindow`/`_output` stripped, strings/objects truncated at 2000 chars (:12-32). `setIterationSelection` (:168-212) resets descendant selections, pulls ancestors to the containing iteration ("inner-pulls-outer"), and tracks `lastSelectedLoopId` as the active context for the Variables panel. Selectors: `selectIterationScope` (innermost selected loop ancestor, iterationScope.ts:30-50), `selectActiveIterationContext` (:64-96), `selectVisibleIterations` (records constrained by ancestor selection; returns fresh arrays — callers MUST memoize, doc :102-106).

### 12. Edge-path highlight & run frontier (`stores/selectors/edgePath.ts`)
`selectEdgePathStatus` (edgePath.ts:106-194) classifies edges `on-path`/`untaken`/`idle`, surviving `execution-finished` (derived from persistent maps). Dual-origin branch identity (`edgeIsBranch` :58-63): canvas edges via `data.branchPath`, imported edges via target `_isChildOf === source`; imported arm matching correlates child `_stepPath` against container `_stepPath` (`childInTakenScope` :42-47, mirrors `FlowCanvasBridge.ExtractBranchKeyFromStepPath`). Live build: a branch arm lights the moment its child is reached (non-idle) without waiting for the container's late `branchTaken` (:140-152). Iteration scoping overrides aggregate when a selection is active (:125-131). Loop arms light when `loopIterations > 0`; parallel fans to all arms; unresolvable correlation returns `idle` ("don't guess" :175, 190). `selectEdgeIsRunningFrontier` (:83-90) keeps exactly one travelling dot on the deepest running block's incoming edge (edge-derived, no `_stepPath` dependency).

### 13. Undo/redo (`stores/slices/undoSlice.ts`)
Bounded 100-snapshot stack of deep-cloned (`JSON.parse(JSON.stringify)`) `nodes`+`edges` only (undoSlice.ts:5, 30-44); undo/redo swap graphs and clear export status (:46-98); `clearHistory` on every graph load (messageBridge.ts:76). Snapshot producers: connect, add block, delete blocks/connections, edit branch, add/remove comment, move blocks (drag start, App.tsx:173), move band (BranchBandsLayer.tsx:28), Auto-layout (useAutoLayout.ts:15), paste (useKeyboardShortcuts.ts:68), edit property (Properties.tsx:1553).

### 14. Clipboard (`utils/clipboard.ts`)
Module-level internal clipboard. `copyNodes` (:15-32) deep-copies selected nodes (minus Start) + fully-internal edges; `pasteNodes` (:38-70) re-ids nodes/edges (`node-paste-<ts>-<n>`), offsets +30/+30, remaps edge endpoints via idMap. Wired to Ctrl+C/Ctrl+V (useKeyboardShortcuts.ts:48-74).

### 15. Keyboard shortcuts (`hooks/useKeyboardShortcuts.ts`)
Ctrl+Z/Y undo-redo, Ctrl+C/V, Ctrl+F search, Delete/Backspace (edges first, then nodes :84-94), Escape (search→context menus→selection), Ctrl+Enter test-step on first selected node, F5 run, F10 debug step. Run/test are blocked while `exportStatus.hasErrors` (:114-117, 136-138); both send `execute-canvas` with the full executable payload.

### 16. Export payload split (`utils/exportGraph.ts`)
`buildExecutableGraphPayload` (:110-146) splits comment nodes into a **flat `comments[]` array** (id/text/color/geometry/attachedToNodeId/kind/anchor — the shape C# matches back to blocks) and strips props equal to blockDef defaults from executable nodes (`stripDefaultProps` :63-104, deep-equality :31-61); appends live `disabledBlocks`. Consumed by Toolbar apply (`apply-yaml`, Toolbar.tsx:54-59) and run/test-step sends.

### 17. Message bridge (`stores/messageBridge.ts`, 512 LOC)
`initMessageBridge` subscribes all inbound handlers then `sendReady()` (:508-509; host queues outbound until `ready`). Highlights:
- `load-graph` (:130-184): stamps `expanded` when `defaultBlockExpanded` is on, sets nodes/edges, synthesizes `__start__` if absent (`ensureStartNodeExists` :32-72 — converts a `_preamble` node's props onto Start, wires Start to the first in-degree-0 node with literal `#666` stroke :68), applies mode-aware layout (§5), resets session state (`clearDirty/clearHistory/clearExecution/clearTimeline/clearExportStatus/clearIterations` :74-81), then **always** restores disabled + expanded sets from node data (even empty — the preset-id-collision leak fix, comment :164-168).
- `apply-result` (:188-212): export status + per-node diagnostics; failure echoes a `show-error` message to the host (:208 — note: raw string type, not in the outgoing registry).
- `execution-started/finished/update` (:215-313): clears run state, flips `isRunning`, routes per-step state/timing/timeline/variables/iterationCount/branchTaken/iterationStack; validates `stepId` presence and the state enum (warn+ignore :233-244).
- `step-output` (:316-330): appends block output and ties the output index into the iteration log.
- `run-output` / `run-output-clear` / `run-output-window-closed` (:333-354): live console mirror with unread-dot gating on `runOutputPoppedOut`.
- `test-step-result` / `test-data-block-result` (:357-394), `variables-snapshot` (:397-405), `debug-paused`/`debug-resumed` (:408-431), `set-target-host` (:434-451), `theme-sync` intentionally ignored — canvas is always dark (:454-456), `layout-restore` (:459-489 — panel sizes, heatmap, default layout mode, canvas settings, snap, bands, compact comments, run-output prefs), `pref-restore` (:492-499 — reducedMotion, iterationHistoryCap).
- Installs `__FLOWCANVAS_TEST_HOOKS__` for e2e (set/clear/snapshot graph via real actions, connect via real `onConnect`, read connectionNotice :83-122).

### 18. MessageBus transport (`MessageBus.ts`)
Singleton wrapping `window.chrome.webview` postMessage/addEventListener (:25-54); falls back to same-window `message` events outside WebView2 (dev/e2e; `event.source !== window` guard :45). `send` logs + invokes the test hook outside WebView2 (:67-83). `sendReady` once-latched (:86-90). Unhandled inbound types are debug-logged and dropped (:99-102); handler exceptions are isolated per handler (:104-110).

### 19. Detached Run Output window (`stores/runOutputWindowBridge.ts`, `panelMode.ts`, `RunOutputWindowApp.tsx`)
`?panel=runoutput` (panelMode.ts:4-6) selects a minimal second app in a second WebView2. `initRunOutputWindowBridge` (:12-39) subscribes only run-output/clear/started/finished/layout-restore(run-output prefs) and sends its own `ready`. Its store instance is independent of the main canvas store (separate page).

### 20. Branch bands (`utils/branchBands.ts`, 278 LOC)
Pure derivation of lane rectangles from `_isChildOf`/`_stepPath`/positions — writes nothing to node data (:1-3). `branchColorVar` (:31-39) is the single branch→token map shared with edges and the Properties chip. Bands box the whole branch **subtree** by stepPath prefix (:188-191), include leading comment pills (:199-204) and fold all anchored comments into `memberIds` so band-drag moves them (:212-217). Two-pass bottom-up growth so nested bands keep full `BAND_PAD` separation, relaxation loop capped at `prelims.length` passes (:231-264). Heights use `estimateNodeHeight` with the live textScale (:105-111).

### 21. Node sizing & styling (`utils/nodeSize.ts`, `utils/nodeStyle.ts`, `utils/blockSummary.ts`, `utils/displayNodes.ts`, `utils/tokens.ts`, `utils/theme.ts`)
- nodeSize.ts: `SPINE_WIDTH` 330 / `CHILD_WIDTH` 300 / `BLOCK_WIDTH_INSET` 30, `COLLAPSED_HEIGHT` 52, `BAND_PAD` 18 (shared layout↔bands), `estimateNodeHeight` (:42-57) — expanded height derived from `summarizeBlock` row count with label-wrap detection (16-char budget).
- blockSummary.ts: visible-row selection (required ∪ non-default), conditional-required logic ported from Properties for readfile/http/interactive (:22-43), secrets masked for `password`/`token` (:10, 66-68).
- nodeStyle.ts: `idleNeon` category ring (:10-16), shadow ladder `resolveNodeShadow` (:33-44).
- displayNodes.ts: `contentSizeComment` strips legacy fixed comment boxes so RF auto-measures (hit-area hijack fix :11-21); `orderCommentsBehind` sorts comments before blocks so blocks win pointer overlaps (:29-32).
- tokens.ts: category CSS-var sets, `mix()` color-mix alpha helper (:44-46), `resolveCssVar` for SVG minimap (:50-55), `DEFAULT_COMMENT_COLOR '#e0c040'` deliberately byte-identical to the C# default (:5-6).
- theme.ts: `applyTheme` flips `data-theme` only (light is a future swap point; runtime is dark-only).

### 22. Comments (`stores/slices/commentSlice.ts`)
`addComment` (:17-43): sticky by default, `leading` anchor when attached; no fixed size (auto-measure); reflow gated on `anchorReservesLayoutSpace`; autosave. `updateComment` (:45-71) merges data/position/size + autosave (no undo snapshot for text edits). `removeComment` (:73-84) snapshots, reclaims reserved space only if the comment reserved any.

### 23. Timeline & variables (`stores/slices/timelineSlice.ts`, `variableSlice.ts`)
Timeline: append entry on `running` with a full variables snapshot (messageBridge.ts:253-262), patch open entries on completion (`updateTimelineEntry` matches `nodeId && !endTime`, timelineSlice.ts:44-50); `scrubTo` selects the node and replays its variable snapshot (:52-63). Variables: change detection vs previous values plus explicit `changedKeys`, 800ms module-timer highlight clear (variableSlice.ts:46-52).

### 24. Run-output classification (`utils/runOutputClassify.ts`)
`classifyRunOutputLine`: banner regex matching Form1's `######` delimiters, conservative error-keyword regex; explicitly cosmetic/best-effort (:6-7).

## Observed gaps & quirks

1. **Paste keeps stale membership metadata pointing at the ORIGINAL nodes.** `pasteNodes` re-ids nodes and remaps edge endpoints but never touches `data.props` (utils/clipboard.ts:44-67) — a copied container child keeps `_isChildOf` (original container id), its original `_stepPath`, and `_membershipFromConnect`. Consequences: branchBands groups the pasted block into the original container's band (branchBands.ts:158-169), treeBuilder nests it under the original container (treeBuilder.ts:36-44), `renumberStepPaths` renumbers it as a sibling **inside the original branch** (childMembership.ts:240-247), and export's metadata-driven regeneration can double-place it. Paste of a container also duplicates `_forceGraphExport` state. No strip occurs at the paste site (useKeyboardShortcuts.ts:63-74). The internal clipboard also survives preset switches (module-level `clipboardData`, clipboard.ts:9), so paste can reference node ids from a different preset.
2. **`breakpoints` Set is never cleared or restored on `load-graph`.** `resetGraphSessionState` (messageBridge.ts:74-81) clears dirty/history/execution/timeline/exportStatus/iterations; the load handler restores disabled+expanded (:177-183) but not breakpoints. Preset node ids collide (`node-1`, `node-2`…), so breakpoints leak onto the next preset's unrelated blocks (known issue; the disabled/expanded leak was fixed, this one was not).
3. **Deleting a node does not purge it from `disabledBlocks`/`breakpoints`/`expandedNodes`.** `removeNodes` filters only `selectedNodeIds` (graphSlice.ts:453). Stale disabled ids are then persisted by every layout autosave (layoutAutosave.ts:60) and shipped in the executable payload (exportGraph.ts:143).
4. **Undo is graph-only and host-blind.** Snapshots capture `nodes`+`edges` (undoSlice.ts:30-44); undo/redo do not restore selection, the debug Sets, `isDirty`, or membership-derived band visuals beyond what's in node props, and **do not trigger `sendLayoutAutosave`** — after Ctrl+Z the host's persisted layout/positions diverge until the next autosaving action. Undo also never clears `isDirty`, so undoing back to the loaded state still reports dirty.
5. **React-Flow-initiated removals bypass undo.** `onNodesChange`/`onEdgesChange` handle `remove` changes (cascade, renumber, membership-revert) but push no snapshot (graphSlice.ts:243-344); only the explicit `removeNodes`/`removeEdges` actions snapshot. The app's own Delete handler routes through the latter (useKeyboardShortcuts.ts:84-94) and no `deleteKeyCode` override was found, so RF's default Backspace delete path can still fire the snapshot-less route.
6. **Comment text edits are not undoable** — `updateComment` has no `pushSnapshot` (commentSlice.ts:45-71), while add/remove are. Inconsistent with the rest of the undo surface.
7. **Timeline memory is unbounded and unsanitized.** Every `running` event appends an entry carrying a **full** variables snapshot (messageBridge.ts:258-261) with none of iterationSlice's sanitization (heavy `_outputwindow` keys, 2000-char truncation — iterationSlice.ts:12-32). Long loop-heavy runs grow `timelineEntries` without cap. Also `updateTimelineEntry` patches **all** open entries for a node id (timelineSlice.ts:44-50), which can mis-attribute durations when the same node has overlapping open entries (parallel branches).
8. **Per-edge selectors are O(N) lookups per edge.** `selectEdgePathStatus`/`selectEdgeIsRunningFrontier` do `edges.find`/`nodes.find`/`edges.some` per edge per evaluation (edgePath.ts:87-89, 109, 119-120). With E edges subscribed during a run this is O(E·N) per store update; acceptable at preset scale today, a hotspot for large graphs.
9. **Layout depth cap silently stops placing.** Containers nested deeper than `MAX_NESTING_DEPTH` 5 are not recursed into (hierarchicalLayout.ts:167) — their children keep stale positions with no warning/diagnostic, and connectionRules imposes no corresponding nesting limit, so the user can build deeper than the layout can place.
10. **Module-level mutable layout state.** `activeSizing` and `commentReserveByTarget` are file globals set at the top of `computeHierarchicalLayout` (hierarchicalLayout.ts:53, 74, 314-324). Safe under the documented synchronous contract, but any future async/parallel layout call corrupts a concurrent pass. Comment sizing is heuristic (33 chars/line, 17px lines, fixed pill steps :60-71) and drifts from real DOM at unusual fonts.
11. **Hex literals outside the token layer.** `ensureStartNodeExists` writes `stroke: '#666'` on the synthesized start edge (messageBridge.ts:68), matching FlowCanvasBridge's grey imports but contradicting the project's "no hex outside tokens" rule; `edgeIsBranch` explicitly works around imported `#555`/`#666` strokes by keying on structure (edgePath.ts:54-56). `resolveCssVar` fallback `'#4a9eff'` (tokens.ts:50).
12. **`show-error` outbound message is stringly-typed** (messageBridge.ts:208) — not declared in `CANVAS_HOST_MESSAGES.outgoing` (communication-message-types.ts:30-48), so the registry undersells the real protocol surface.
13. **Search matches hidden metadata.** `setSearchQuery` substring-matches `JSON.stringify(props)` (uiSlice.ts:236-239), so queries like "steps" or "child" hit every imported block via `_stepPath`/`_isChildOf` — noisy results for a user.
14. **Switch `default` / try 4th-branch inference holes.** `inferDefaultBranchMetadata` can never author a switch `default` arm (always `cases/N/do`, graphSlice.ts:116-125) — only manual edge-metadata editing can; a 4th try-branch falls back to a **duplicate** `catch` branchPath (graphSlice.ts:113). Elif arms are created with `condition: ''` (graphSlice.ts:98-101), valid-looking until export-time validation.
15. **Dead/latent theming surface.** `setTheme`/`toggleTheme` (uiSlice.ts:158-159) and `applyTheme`'s light branch exist while `theme-sync` is intentionally ignored (messageBridge.ts:454-456) — dark-only runtime with vestigial light-mode plumbing.
16. **Leftover artifact in repo:** `stores/slices/__tests__/graphSlice.rewireProbe.test.ts.tmp` — a `.tmp` test file checked in.
17. **`appendRunOutput` re-splits the whole buffer per chunk** (executionSlice.ts:119-127): O(buffer) split/join on every output message; with high-rate output and a 5000-line buffer this is measurable on the UI thread. Cap (5000) and iteration snapshot bounds (2000 chars, cap 500) are hardcoded, only `iterationHistoryCap` is user-tunable.
18. **Multiple disconnected roots get no start wiring.** `ensureStartNodeExists` wires Start to the **first** in-degree-0 node only (messageBridge.ts:59-71); other roots remain orphans (kept by keepOrphans, appended by explicit Auto-Layout) with no user-facing indication of which root actually runs first.
19. **`onConnect` undo snapshot fires before membership/renumber but after the guard** (graphSlice.ts:356) — correct; noted because `updateNodeProp` (graphSlice.ts:510) deliberately does **not** snapshot per keystroke and relies on Properties.tsx:1553 pushing one per edit session — a property edited via any future non-Properties path would be silently un-undoable.
20. **Eviction can orphan iteration records.** Documented at iterationSlice.ts:140-143: evicting an outer record leaves inner records with dangling `parent.seq`; `selectVisibleIterations` then filters them out (iterationScope.ts:107-121), so under long runs the stepper silently shows fewer inner iterations than `totalIterations` reports.
