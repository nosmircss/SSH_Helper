Interactive Build Features

▶ Test Step
Right-click any block → "Test Step" (or Ctrl+Enter).
Executes that block and all prerequisite blocks above it on a single host.
Output appears inline on the block. Variables are set for downstream use.
🔍 Live Pattern Tester
For EXTRACT blocks: as you type a regex pattern, it runs against the actual output from the previous SEND block. Shows matches in real-time with capture group highlighting. No more guess-and-check.
🔀 Condition Preview
For IF/WHILE/SWITCH blocks: shows which branch would be taken based on current variable values from executed steps. The taken branch glows, the other dims.
📊 Variable Trail
As you execute steps, the Variable Inspector shows a timeline of how each variable changed. Click any variable to see which block set it and what it was before/after.
🎯 Smart Suggestions
After executing a SEND, the output is analyzed. If it looks tabular, suggest an EXTRACT with a pre-built pattern. If it contains an error, suggest a TRY/CATCH wrapper. Contextual "Add next step" recommendations.
🔄 Re-execute from Here
Changed a block in the middle of the flow? Right-click → "Re-execute from here" runs from that point forward, using cached variables from blocks above. Faster iteration without re-running the whole script.
