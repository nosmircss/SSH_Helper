FlowCanvas v2 — Feature Ideas

Select ALL the features that excite you. We'll prioritize after.

🎯 Core: Interactive Debugging

1

Step-Through Execution

Step Over / Step Into / Continue / Stop. Each block lights up as it executes. See real SSH output inline. Pause at any point.

2

Breakpoints (Already Partial)

Click the red dot to set breakpoints. Execution pauses there automatically. Wire up the existing DebugState infrastructure that's already in the codebase.

3

Conditional Breakpoints

Right-click a breakpoint to add a condition (e.g., firmware_ver != "17.9"). Only pauses when the expression is true.

4

Live Variable Watch

Variable Inspector updates in real-time as you step. See values change after each block. Highlight changed variables in yellow flash.

5

Per-Block Output Panel

Click any executed block to see its SSH output. Output stays attached to the block, not just the latest one. Scrollable output history per block.

🧭 Navigation & Organization

6

Auto-Organize / Re-Layout

Button to re-arrange all blocks into a clean top-to-bottom flow. Respects branching structure. Animated transition so you don't lose your bearings.

7

Collapsible Groups

Collapse if/foreach/try containers into a single summary block. Expand to see internals. Reduces visual clutter for large scripts.

8

Enhanced Minimap

Minimap shows execution progress (green trail). Click minimap to jump. Show breakpoint markers on minimap. Current position indicator.

9

Search / Find Block

Ctrl+F to search block labels, commands, or variable names. Highlights matches on canvas. Jump between results.

⚡ Power Features

10

Undo / Redo

Ctrl+Z / Ctrl+Y for all canvas operations — add, delete, move, connect, property edits. Essential for confident editing.

11

Copy / Paste Blocks

Select one or more blocks, Ctrl+C / Ctrl+V. Duplicates with connections. Great for repeating patterns across the flow.

12

Multi-Select & Bulk Operations

Shift+click or drag-select multiple blocks. Move them together, delete together, or group them. Selection box highlighting.

13

Snap-to-Grid

Blocks snap to an invisible grid when dragged. Keeps everything aligned. Toggle on/off. Works with auto-organize.

14

Execution History / Timeline

After a run, scrub through a timeline to see the execution path. Which blocks ran, in what order, how long each took. Replay visualization.

🎨 Visual & UX Polish

15

Rich Block Status Indicators

Running = blue pulse, Success = green check, Error = red X with error message tooltip, Skipped = grey dash. Duration badge on completed blocks.

16

Animated Edge Flow

During execution, animated dots flow along edges showing data movement. Direction, speed, and color indicate flow state. "Marching ants" style.

17

Theme Toggle (Dark/Light)

Switch between dark (current) and light theme. Match the WinForms app theme preference.

18

Block Comments / Annotations

Add sticky notes to blocks or areas of the canvas. Yellow note cards that explain WHY, not just WHAT. Great for team documentation.

🔧 Advanced Debugging

19

Hot-Edit During Pause

While paused at a breakpoint, edit the next block's properties before continuing. Change a command mid-run without restarting.

20

Edit Variables While Paused

In the Variable Inspector, click a value to change it mid-execution. Test "what if" scenarios without restarting the flow.

21

Skip / Disable Blocks

Right-click → Disable. Block turns grey and gets skipped during execution. Quick way to test partial flows without deleting blocks.

22

Run From Here

Right-click any block → "Run from here". Skips all blocks before it. Great for testing the second half of a flow without re-running the first half.
