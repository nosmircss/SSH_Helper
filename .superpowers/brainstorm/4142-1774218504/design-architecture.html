Build Order (4 Phases)
Phase 1: Foundation                    Phase 2: Canvas Features
─────────────────────                  ─────────────────────────
 ① Zustand store setup                 ④ Multi-select & bulk ops
 ② Message bridge                      ⑤ Snap-to-grid
 ③ Theme toggle                        ⑥ Undo / Redo
                                        ⑦ Copy / Paste
        │                               ⑧ Search / Find
        ▼                               ⑨ Auto-layout (dagre)
Phase 3: Execution Wiring              ⑩ Block comments
─────────────────────────
 ⑪ Rich status indicators                     │
 ⑫ Animated edge flow                         ▼
 ⑬ Step-through execution     ←──── Phase 4: Advanced
 ⑭ Breakpoints wiring         ─────────────────────────
 ⑮ Live variable watch         ⑰ Skip / Disable blocks
 ⑯ Per-block output panel      ⑱ Execution timeline
New Message Protocol (C# ↔ React)
C# → React (new)
execution-started — run begins
execution-finished — run ends + duration
step-output — SSH output per block
step-timing — start/end timestamps
variables-snapshot — vars + changedKeys
theme-sync — dark/light from WinForms
React → C# (new)
disable-block — skip/enable a block
debug-action — extended with step-into
