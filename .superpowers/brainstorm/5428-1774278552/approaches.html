FlowCanvas Host Targeting — 3 Approaches

How should the canvas know which host to run against?

A

Host Bar (Recommended)

A slim, always-visible bar at the top or bottom of the FlowCanvas showing the active host as a read-only summary row. Shows Host_IP, port, username, and a few key variables. Auto-populated on canvas open using fallback logic.

FlowCanvas with Host Bar
▶ Run 🐛 Debug ⏹ Stop 💾 Save
🎯 TARGET: Host: 192.168.1.10 Port: 22 User: admin env: production Change in main grid ↗
[ Flow Canvas Graph Area ]

Pros

  • Always visible — you always know what you're running against
  • No extra clicks to run — just hit ▶
  • Minimal UI footprint
  • Simple C# ↔ React integration (one message to sync host data)

Cons

  • Takes vertical space (though slim — ~30px)
  • Read-only — must go back to main form to switch hosts
B

Host Chip in Toolbar

Embed a compact "host chip" directly in the existing toolbar row, next to the Run button. Shows just the Host_IP. Hover or click reveals a tooltip/popover with the full row details.

FlowCanvas with Host Chip
▶ Run 🎯 192.168.1.10 🐛 Debug ⏹ Stop 💾 Save
Target Host Details
Host: 192.168.1.10 Port: 22 Username: admin env: production
Change in main grid ↗
[ Flow Canvas Graph Area ]

Pros

  • Zero extra vertical space — fits in existing toolbar
  • Clean, minimal — just a chip next to Run
  • Details available on demand via popover

Cons

  • Less visible — easy to miss which host you're targeting
  • Popover requires extra interaction to see details
  • IP-only chip might not be enough context at a glance
C

Collapsible Host Panel

A panel (like the existing Properties or Variable Inspector panels) that shows the target host as a mini data-grid row. Can be collapsed to a thin strip showing just the IP, or expanded to show all columns.

FlowCanvas with Host Panel (expanded)
▶ Run 🐛 Debug ⏹ Stop
🎯 Target Host ▼ collapse
Host_IP port username env region
192.168.1.10 22 admin production us-east-1
[ Flow Canvas Graph Area ]

Pros

  • Shows the most detail — full row with all columns
  • Collapsible — can minimize when not needed
  • Familiar pattern — matches existing canvas panels

Cons

  • Heaviest UI — most vertical space when expanded
  • More complex to implement (collapsible panel + table rendering)
  • May feel like overkill for "just show me which host"
